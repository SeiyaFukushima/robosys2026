# lapstat

lapstatは、レースのラップタイムを集計するコマンドラインツールです。

標準入力からラップタイムを読み込み、ベストラップ、ワーストラップ、平均ラップを計算して表示します。

## 機能

- ラップタイムの読み込み
- ベストラップの計算
- ワーストラップの計算
- 平均ラップの計算
- 不正な入力の検出

## 動作環境

- Python 3

## 使用方法

ラップタイムを秒単位で、1行に1つずつ記述したテキストファイルを用意します。

例：laps.txt

    91.122
    90.342
    92.093
    91.674
    90.510
    89.981

以下のコマンドで実行します。

    ./lapstat.py < laps.txt

## 実行結果

    Fastest lap: 89.98 sec
    Slowest lap: 92.09 sec
    Average lap: 90.95 sec

## テスト

以下のコマンドでテストを実行できます。

    python3 -m unittest


## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.10〜3.14
